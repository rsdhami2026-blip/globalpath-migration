GLOBALPATH MIGRATION — Owner-editable profile demo

1. Upload index.html to your website host (replace the previous index.html).
2. Click the "Owner Edit" button at the bottom-right of the website.
3. Demo password: change-me-123
4. Edit owner name, position, HR name, company description and upload a profile photo.
5. Save Changes.

IMPORTANT SECURITY / STORAGE LIMIT:
This is a front-end demo. The demo password is visible in the page source and profile changes are stored only in the current browser (localStorage). They will not sync to other devices or visitors. Do not use this for confidential data or real admin security.
For real owner-only access with secure login, shared profile updates, applicant accounts, private CV uploads and a database, deploy a backend with server-side authentication and database/storage.
